# 📈 Invest Me — 人体资本交易所 (Human Capital Exchange)

> **核心理念:** "Your Life, Publicly Traded." (你的人生，公开交易)

Invest Me 是全球首个基于 **Bio-Fin (生物金融)** 仿真引擎的自我管理应用 MVP。我们颠覆了传统的意志力驱动模式，利用金融工程 (K线、波动率、指数) 将枯燥的坚持转化为刺激的“资产增值”，将放纵转化为昂贵的“资产减值”。

---

## ✨ 核心 MVP 特性 (Minimum Viable Product V1.0)

我们用 20% 的工作量实现了 80% 的专业金融终端用户体验。

* **专业 K 线图 (Candlestick)**：从单一线条升级为专业的红绿蜡烛图，并引入 **成交量 (Volume)** 和 **均线 (MA)**，提供完整的看盘体验。
* **实时 Bio-Fin 引擎**：股价 ($ME) 实时波动。默认趋势为 **熵增下跌**（不努力，资产自动贬值），点击“锻炼”则注入正向 **动量**，实现符合惯性规律的持续上涨。
* **经济系统 ($CASH)**：引入现金流。锻炼/自律行为产生 **$CASH 分红**。
* **危机与救市**：当股价暴跌时（动量低于阈值），图表会进入**红色危机模式**。用户可消耗 **$CASH** 购买 **“后悔药 (Resurrection Coin)”** 来强行扭转下跌趋势。
* **宏观参照系**：显示 **$IMCI (全球大盘指数)**，让用户实时对比是否跑赢了“平均水平”。

## 🛠️ 技术栈 (Tech Stack)

该项目是使用现代前端技术栈构建的高性能实时图表应用。

| 类别 | 技术 | 描述 |
| :--- | :--- | :--- |
| **前端框架** | `React` / `TypeScript` / `Vite` | 快速、组件化开发环境。 |
| **图表核心** | `lightweight-charts` (v5+) | TradingView 官方高性能图表库，用于渲染 K 线和指标。 |
| **样式语言** | `Tailwind CSS` | 用于实现快速、响应式的 **Bloomberg Terminal** 风格暗黑界面。 |
| **逻辑核心** | `useBioFinEngine` (Custom Hook) | 封装了物理计算、状态管理和实时心跳 (Ticker) 逻辑。 |

## 🚀 本地运行与演示 (Setup & Demo)

### 运行项目

1.  **克隆或下载代码**
2.  **安装依赖**
    ```bash
    npm install
    # 或 yarn install
    ```
3.  **启动应用**
    ```bash
    npm run dev
    ```

### 游戏演示 (How to Play)

| 行为 | 目标 | 效果 (股价 & $CASH) |
| :--- | :--- | :--- |
| **静置/不操作** | 观察熵增 | $ME 缓慢下跌，动量衰减至负值。 |
| **点击 Long (锻炼)** | 注入动量 | $ME 股价开始持续上涨，并获得 **+$5 现金分红**。 |
| **点击 Short (熬夜)** | 消耗精力 | $ME 股价加速下跌，动量池被清空甚至变负。 |
| **触发 CRASHING** | 体验恐惧 | 股价暴跌，图表变红，底部出现 **救市按钮**。 |
| **点击 RESURRECTION** | 亡羊补牢 | **消耗 $50 现金**，股价趋势立刻被扭转为强力反弹。|
